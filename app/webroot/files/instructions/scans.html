DEXA Chart Review Instructions

Please review each DEXA scan in its entirety and document all regions with corresponding T and Z scores when available.

  1. Please select an event and download the PDF.
  2. Please review the entire PDF as sometimes the regions are specified in the intro paragraph and sometimes in the summary with the T and Z scores.
  3. Please document for each body region:
    1. body region (e.g., lumbar spine)
    2. laterality if relevant (L vs R), leave blank if not relevant (e.g. spine)
    3. T scores
    4. Z scores

Notes:

  1. Please use spine when it is an overall spine value or when location of spine is not specified. Please note that sometimes the location in the spine (e.g. lumbar) is in the paragraph descriptor even if it is not listed with the T and Z scores themselves. Please also note some include both an overall spine and a specific spine region (e.g., lumbar). When that occurs, please include both.
  2. Please note that there were brief periods where only T scores and not Z scores were provided. However for the majority of individuals, there will be both for each region.
  3. When noted (e.g., for most hip values), please include laterality (e.g. L and R). This is important for people who have multiple scans over time of the same region.
  4. Please use hip when more specific information is not provided.
  5. Please include all variations of lumbar (e.g. L1-L2; L4) as lumbar. We are not trying to parse to the level of the specific vertebrate as that is often not given or includes multiple.
  6. If body regions are included that are not on the dropdown list, please include them using Other and typing in the region. Any that are found frequently will be added to the dropdown list for the future.
